# Parrot Protocol

Parrot Protocol covers the connection between Parrot devices, Bridge integrations and Parrot services. This repository also tracks planned WebSocket access for third-party applications.

## Current work

- **Open-source release in progress:** we are preparing Parrot Protocol for an open-source release. Product source code has not been published in this repository yet.
- **Embedded device support in progress:** we are extending support to different embedded devices. Supported devices and availability will be announced as they are ready.

## Feedback and progress

Use this repository for protocol, Bridge integration and device connection feedback. It currently provides public issue tracking and product planning.
